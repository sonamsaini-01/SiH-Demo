# SiH-Demo
This video demonstrates the working prototype of NETRA, our proposed solution for Smart India Hackathon (SIH). NETRA is a passive, AI-powered network threat analytics system designed to monitor one-way network traffic without decrypting or disrupting the existing communication flow.

The prototype demonstrates the complete workflow of NETRA, including:

• Passive Traffic Capture – Observes network traffic without interfering with communication.  
• Normalization Module – Collects inputs from multiple adapters and converts different data formats into a unified format for further analysis.  
• Flow Generation & Feature Extraction – Categorizes packets and extracts important traffic characteristics such as packet size, timing, rate, protocols, and behavioral patterns.  
• AI/ML-Based Threat Detection – Analyzes extracted features to identify and classify suspicious network behavior across multiple threat categories.  
• Smart Alert Correlation – Correlates repeated attack patterns over time to avoid generating unnecessary duplicate alerts and helps improve the severity and relevance of security notifications.  
• Graphical Security Dashboard – Presents traffic analysis, detected threats, and alerts through an intuitive graphical interface, supporting easier monitoring and investigation.  
• SOC & Forensic Assistance – Provides structured threat information and correlated observations that can assist security teams in investigation, analysis, and incident response.

NETRA follows the principle of “Zero Decryption, Zero Disruption, Maximum Visibility”, focusing on intelligent analysis of network behavior while maintaining the existing communication environment.

The video showcases the current prototype implementation and demonstrates how the proposed architecture can be used for real-time network monitoring, threat detection, alert correlation, and security analysis.
